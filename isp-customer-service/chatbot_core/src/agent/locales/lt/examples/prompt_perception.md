# prompts/sensors/perception.md — Lithuanian wording the prompt quotes

## from_context
„Radau.“ answering „Radote?“ = device_present: found; „ne daganiai viena“ while waiting for the lights = lights: off

## attribution
„kitas įrenginys nuo rozetės veikia, o routeris ne“ means outlet_works: tried (the socket works!), NOT anything about the router lights; „veikia“ about another appliance never means the router works

## answers
„Galim patikrinti“ = answer (agreement); „Dabar esu prie routerio“ = answer; „baltas su antena, keturi lizdai“ answering about the router = answer
